Recepção de arquivos

Aponte a câmera para a tela transmissora e mantenha o QR code no enquadramento.

Conectar a câmera

Permita o acesso à câmera para ler os códigos e reconstruir o arquivo neste dispositivo.

Condições de captura

  1. Abra Transmitir no dispositivo de origem.
  2. Enquadre o QR code inteiro na câmera.
  3. Mantenha os dispositivos estáveis e aguarde.
  4. Salve o arquivo quando a verificação terminar.

A câmera precisa de HTTPS ou localhost no navegador.
