# 1. Registrar decisões de arquitetura (ADRs)

- Status: aceito
- Data: 2026-09-17

## Contexto
Um TCC precisa justificar as escolhas de projeto de forma rastreável, e o próprio
desenvolvimento se beneficia de um histórico do "porquê".

## Decisão
Registrar decisões significativas como ADRs curtos e numerados em
`docs/decisions/`, no formato **Contexto / Decisão / Consequências**.

## Consequências
- Histórico auditável das escolhas e dos seus motivos.
- Base pronta para o texto de fundamentação do TCC.
